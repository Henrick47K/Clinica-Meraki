# Clinica-Meraki

### Autores da equipe: Solano Prevosti Bastos, Henrique Duarte Lima, Miguel Ribeiro Fleck, Jonatha Lohan Moreira da Silveira

Escolhemos o ciclo ágil, pois, através da nossa discussão chegamos na conclusão que seria a metodologia mais viável, nosso projeto será sobre uma clinica multidisciplinar, e um dos nossos integrantes trabalha nela, com isso não teremos problema com feedbacks diários com o cliente, ele está disposto a sempre estar em contato conosco. Os nossos requisitos não estão bem definidos, com o tempo podemos adicionar mais funcionalidades ou até mudar algumas coisas dependendo do que o cliente deseja, o que também se encaixa no ciclo ágil, a clinica tem uma grande necessidade dos agendamentos, então ela preza por entregarmos por partes, não necessita do projeto final logo, o que ajudou muito a também escolher essa metodologia para o projeto.
